# Weekly Shopify profit-close checklist

Use with the [AfterCosts free browser tool](https://aftercosts.jebraeili-nima.workers.dev/). This is not professional accounting advice.

- [ ] Use a complete date range and one currency.
- [ ] Keep the source Shopify export unchanged.
- [ ] Group repeated line-item rows by unique order Name before totaling.
- [ ] Check cancellations, unsettled orders and refund statuses.
- [ ] Map SKU costs to the correct historical period; flag unknown costs.
- [ ] Verify refund dates, amounts and tax effects against source records.
- [ ] Compare estimated fees with actual card processor statements.
- [ ] Distinguish shipping charges collected from merchant-paid shipping labels.
- [ ] Match advertising and overhead to the same exact reporting period.
- [ ] Reconcile payouts and reserves separately from order contribution.
- [ ] Document assumptions and validate financial reports with a bookkeeper.

## Synthetic example
Two rows carrying the same order Name and $120 order Total represent **$120, not $240**, in gross order revenue. If tax is $10, mapped costs $52, fees $3.78 and merchant-paid shipping $6, then estimated contribution before ads is **$48.22** ($120 − $10 − $52 − $3.78 − $6).
